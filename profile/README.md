## Hi there 👋

[Institute of Archaeology of the Czech Academy of Sciences, Brno](https://www.arub.cz/) (ARUB) is a research organization investigating (mostly) central European (pre)history.

Under this GitHub organization, we will organize code etc. related to the institutes computational archaeology activities!


### Links

- Our homepage is [https://www.arub.cz/](https://www.arub.cz/)
- Find us on [Facebook](https://www.facebook.com/Archeologicky.ustav.Brno) and [YouTube](https://www.youtube.com/@ARUBrno/) (both with content mostly in the Czech language)
- Our data is published in a [Zenodo community](https://zenodo.org/communities/arub/)
